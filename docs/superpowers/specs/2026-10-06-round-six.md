# Round six — end now, resume later

Date: 2026-10-06.

- **Sessions are conversations.** `SessionKey` is account + Claude Code session id (was account
  + pid). macOS reuses pids within days, and one process holds several conversations after
  `/clear`; the pid is now a field used only to reach the terminal. Pins, mutes and snoozes saved
  under `account:pid` move to the running session's id on start (`Prefs::migrate_pid_entries`).
- **Alive** means a status file names the session; sessions known only from events count as
  running only if their process is alive, belongs to no other session and started before the
  session's first event (`process_started_ms`, from `proc_pidinfo`).
- **History** reaches back as far as Claude Code keeps transcripts (`cleanupPeriodDays`, default
  30, per account). Ended sessions whose transcript is gone are hidden
  (`transcript::kept_session_ids`, listed once a minute; the transcript found while a session ran
  counts too).
- **Names survive the process:** hook and report events carry the status file's `name`.
- **Keys:** `X X` ends a waiting session with `/exit`; the selection stays on it. `P` on an
  ended session saves it under "Saved to resume"; resuming (⏎, or `A A` into the other account)
  removes it from there. Rows and the detail show how many days a session can still be resumed.

Verified live with throwaway Haiku sessions: `X X` ended the process and kept it selected, `P`
saved it, `⏎` resumed the same session id in a new tab, which still knew its code word.
